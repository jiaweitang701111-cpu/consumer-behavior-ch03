## 操作

- 下一步／上一步：`→` `←`、空白鍵，或點投影片右側／左側；手機可左右滑動
- 跳頁：輸入頁碼再按 `Enter`，或在網址後加 `#頁碼`（例如 `#47`）
- `O` 總覽、`F` 全螢幕、`I` 開啟本頁互動（手機點底部的「★ 互動」）
- 手機直立時只顯示投影片（置中），底部是翻頁列；手機橫放時投影片放到最大
